侧映 0.2.0 — 鼠标快捷键
========================

运行环境：Windows 10 1703 或以上 / Windows 11，64 位。
双击“侧映.exe”即可运行，不需要安装鼠标驱动。

第一次设置
----------
1. 连接要使用的鼠标，打开侧映。
2. 在主窗口中按一下真实鼠标的侧键，确认当前鼠标与按键位置。
   如果有闲置无线接收器，Windows 可能同时报告多个鼠标来源；
   此时这一步用来明确当前真正使用的鼠标。
3. 点击“1 / 2 个侧键”选择鼠标的实际侧键数量。
4. 点击鼠标图中的侧键或右侧卡片，选择常用快捷键，
   或点击录制区域后直接按下键盘组合；再点击“保存绑定”。
5. 最小化或关闭主窗口，映射会在系统托盘中继续运行。

新鼠标默认保留鼠标原功能，不会自动替你设置复制或粘贴。
主窗口处于前台时，侧键只用于辨认位置，不执行已绑定快捷键。
录制时按 Esc 可以取消；没有录制时，按 Esc 关闭编辑对话框。
主窗口支持 Tab / Shift+Tab 切换操作，Enter 或 Space 确认。

手动切换方案
------------
每只鼠标可以保存多套侧键绑定，例如“办公”“浏览”“剪辑”。
1. 点击右侧上方“＋ 新建”，输入名称，保存。
   新方案会复制当前方案的绑定，之后可独立修改。
2. 点击“方案 · 名称”下拉按钮，选择要使用的方案，立即生效。
3. 同一个下拉菜单可以重命名或删除当前方案；至少保留一套。
4. 不想打开主窗口时，右键托盘图标 → “切换方案”。
   托盘切换的是正在使用的鼠标，主窗口选择的是正在编辑的鼠标。
5. 快捷键速览会显示当前鼠标、方案名称和这套绑定。

不同鼠标各自记住所选方案，退出、重启、拔插后仍会恢复。
每只鼠标最多保存 32 套方案。改键只影响当前方案。
此版本只提供手动切换，不会根据前台应用自动切换。

从 0.1.0 升级
-------------
先从托盘退出旧版，再用新程序替换原目录中的“侧映.exe”。
请保留原来的 config.json；也可把该文件复制到新版程序旁。
旧绑定会自动成为“默认方案”，首次保存新版配置前会生成
config.json.v1.bak 原样备份。升级后的配置格式为第 2 版，
旧程序不能直接读取。需要退回旧版时，先退出侧映，
再将备份另存为 config.json，保留新版配置以免丢失多方案内容。

换鼠标与速览
------------
拔掉 A 再接入 B，侧映会载入对应设备的绑定。
识别不确定时，会保留原功能；打开主窗口并按一下侧键重新确认。
Ctrl + Alt + M 可以显示 / 收起当前鼠标的绑定速览。
也可从托盘菜单打开速览。如果该快捷键已被其他软件占用，使用托盘入口。
速览小窗不抢走当前软件焦点；按 Esc 收起。
主窗口的“映射已开启”开关和托盘菜单都可以随时暂停映射。
从托盘菜单选择“退出侧映”，程序退出，鼠标恢复原有功能。

配置文件在哪里
--------------
所有鼠标名称、侧键数量、方案、绑定及当前选择保存在程序旁的 config.json。
移动或备份时，请带上整个文件夹，尤其是 config.json。
程序需要对所在文件夹有写权限。
配置损坏时不会覆盖原文件，程序会暂停映射并提示。
开机启动默认关闭；只有在设置里勾选后才写入当前用户的启动项。
移动文件夹后，如果开启过开机启动，请重新关闭再开启一次以更新路径。

本版范围
--------
本版针对“同一时刻只使用一只鼠标”的日常快捷键映射。
触摸板（只报告 2 / 3 个按钮）和明确的 Windows 系统虚拟鼠标不参与自动切换。
同时使用两只真实鼠标并让它们独立映射，不属于本版支持范围。
若收到另一真实鼠标的输入，程序会暂停映射，等待在主窗口重新确认。
普通鼠标钩子是全局的，不提供物理设备身份；因此无法保证两个真实鼠标
恰好在无移动、无预先确认的情况下交替按侧键时，首个事件属于哪个设备。
使用同一无线接收器且向系统报告完全相同身份的两只鼠标，不能自动区分。

支持 Windows 标准侧键 XButton1 / XButton2，支持一次按下触发一个快捷键。
不包含宏、长按重复、手势或厂商专用 HID++ 按键；也不会读取厂商软件内的绑定。
录制的目标为普通按键或修饰键加普通按键，不支持仅发送一个修饰键。
系统保留的 Ctrl+Alt+Del、Win+L 等组合可能不能录制或不能用于普通程序。
快捷键发送受 Windows 权限限制；如需作用于以管理员身份运行的软件，
请用相同权限启动侧映。普通软件无需管理员权限。
若同时运行厂商改键工具或其他鼠标改键工具，请只让一套工具处理侧键。
