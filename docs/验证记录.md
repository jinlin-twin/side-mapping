## 实机仍需用户确认

尚未物理按下用户的两只鼠标，也未替用户录入真实侧键绑定。实际 USB 拔插、休眠后恢复及具体目标应用接收快捷键的效果，需要分别用两只实物鼠标确认。无驱动版本只支持同时使用一只物理鼠标；多个真实鼠标同时独立映射不在支持范围。
