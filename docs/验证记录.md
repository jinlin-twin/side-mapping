## 原生集成自检

`--smoke-test build/native-smoke-desktop` 在正常桌面权限下退出码为 0：

```text
PASS: native window, input hooks, raw input registration, no-activate quick window,
isolated config save, dialog actions, and clean shutdown.
hook_ready=1 raw_ready=1 tray_ready=1 candidates=2
```

自检以关闭映射的状态使用独立配置目录，确认原生窗口创建、全局输入钩子安装、Raw Input 注册、托盘图标、速览窗不激活样式、编辑与保存操作及进程退出。没有写入实际用户绑定或开机启动项。

## 视觉检查

`--render-preview build/native-preview` 使用最终程序的 Direct2D / DirectWrite 实际绘图代码输出主窗口、单侧键、编辑器、设置及速览截图，已检查中文文本、按钮与内容边界。此模式不安装输入钩子，不创建托盘，不读取或写入用户配置。

## 实机仍需用户确认

尚未物理按下用户的两只鼠标，也未替用户录入真实侧键绑定。实际 USB 拔插、休眠后恢复及具体目标应用接收快捷键的效果，需要分别用两只实物鼠标确认。无驱动版本只支持同时使用一只物理鼠标；多个真实鼠标同时独立映射不在支持范围。
