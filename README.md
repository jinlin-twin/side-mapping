# 侧映

中文、便携的 Windows 原生鼠标侧键快捷键映射工具。C++20 / Win32 / Direct2D / DirectWrite，单进程、无浏览器内核，配置保存在程序旁。

## 运行

打开 `dist/侧映.exe`。首次使用在主窗口按一下鼠标侧键，选择 1 或 2 个侧键，再点击卡片录入快捷键。新设备默认保留原功能。关闭窗口后留在托盘；从托盘菜单退出才结束进程。

`Ctrl+Alt+M` 打开当前绑定速览。配置在 `dist/config.json`，可以随整个成品目录移动。详细操作与本版边界见 `docs/使用说明.txt`。

## 手动方案（0.2.0）

每只鼠标支持最多 32 套方案。主窗口右侧“方案”下拉按钮切换，“＋ 新建”复制当前绑定并创建独立方案，下拉菜单支持改名、删除，最后一套不能删除。托盘“切换方案”针对实际使用的鼠标，速览同步显示方案名称。每只鼠标分别保留当前方案；不根据前台应用自动切换。

0.1.0 的单套绑定自动迁移为“默认方案”。首次保存前按原字节备份旧配置到 `config.json.v1.bak`，然后以第 2 版 JSON 保存方案列表和选中项。请先退出旧程序再替换 EXE，并保留原配置；旧版本无法直接读取第 2 版配置。

## 设备策略

为一次只使用一只物理鼠标设计。Raw Input 识别设备，低级鼠标钩子拦截标准 XButton1 / XButton2，独立消息线程发送键盘快捷键。界面绘制与输入线程分离。下压与抬起成对拦截，暂停或断开设备后仍处理已拦截的抬起；注入事件不会重新触发映射。

单一候选鼠标自动载入。两个按钮的触摸板和明确的系统 VHF 虚拟鼠标不参与选择。存在闲置接收器时，在主窗口实际按侧键确认使用中的设备，并记住该选择；新接入的唯一候选设备自动切换。若后台出现其他真实鼠标活动，则暂停并要求重新确认。普通鼠标钩子没有设备身份，此策略**不能提供两只物理鼠标同时独立映射**，也不能可靠区分同一接收器报告相同身份的不同鼠标。

配置优先用设备路径精确匹配；路径因 USB 端口变化时，只有硬件标识唯一匹配才复用档案。两个同型号且硬件标识重复的档案不作猜测。配置按 UTF-8 JSON 原子替换；解析失败保留原文件并暂停映射。注册开机启动默认关闭，仅用户主动点击时修改当前用户 Run 项。

## 构建与验证

在 PowerShell 中运行：

```powershell
.\tools\bootstrap.ps1
.\build.ps1 -Test
```

编译工具为官方 llvm-mingw `20261006` x64 UCRT 便携包，下载在本地 `.tools`，有发布摘要时校验 SHA-256，不修改系统 PATH。JSON 使用 nlohmann/json `3.12.0`，头文件与 MIT 许可证放在 `third_party`。

`build/core-tests.exe` 检查配置隔离、Unicode、损坏文件保护、设备匹配、鼠标事件配对、注入事件过滤、暂停与已有物理修饰键保护。应用可用以下命令通过实际原生绘图代码生成 QA 图片，该模式不装钩子、不写用户配置、不添加托盘或开机启动：

```powershell
.\dist\侧映.exe --render-preview .\build\native-preview
```

`--smoke-test <独立目录>` 安装实际输入钩子并保持映射关闭，在独立配置中执行编辑与保存检查，然后自动退出。正常桌面权限下也会验证托盘图标创建。验证结果和尚需实物确认的范围见 `docs/验证记录.md`。

不需要联网即可运行最终程序。目标为 Windows 10 1703+ / Windows 11 x64；未签名的本地构建。
